# Legal notes

This file records how QuillLoom provides a complete web-editing command set while avoiding other vendors' trademarks and copyrights. It summarizes the project's practice, the same practice the other Quill apps follow; it is not legal advice.

## Clean room

- **Functionality and command names.** Web-editing operations (Insert Hyperlink, Split Cells, Apply Source Formatting, Update Attached Pages, Publish Site, Auto Thumbnail, Check Links) are functional ideas named with ordinary descriptive words. Functionality is not protected by copyright, and descriptive terms are not trademarks for those functions.
- **Menu arrangements.** The classic menu bars place commands where the editors people learned placed them, so that existing skills carry over. A menu arrangement is a functional method of operation. QuillLoom's labels, tooltips, dialogs, help text and icons are written for this project; no text, images, icons or code from those programs or their help files were copied.
- **File formats.** HTML, CSS, JavaScript, XML, SVG, MHTML (RFC 2557), ZIP, the WordPress eXtended RSS export format, WordPress block markup and theme structure, the Weebly theme tag format, and the page-template and library-item comment markers are publicly documented or observable formats. QuillLoom reads and writes them so that users can work with their own files. Converters were written from public documentation and from files made for this project (tests/fixtures).
- **Templates and components.** The built-in site templates, page templates, components, themes, table styles and clip art are original work, released under the MIT License with the app.
- **Imported templates.** Third-party templates that users import keep their own licenses. QuillLoom reminds users that paid templates are licensed to the buyer and that free templates may require attribution.

This is nominative use; it does not imply affiliation, sponsorship or endorsement. These names are trademarks of their respective owners.

## AI providers

Provider names appear only to identify the service a user chooses to connect. QuillLoom has no server; requests go directly from the user's device to the provider the user configured, under that provider's terms.
